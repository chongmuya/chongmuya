# 행사·출석 파일럿 QA

2026-11-20, [draft #59](https://github.com/chongmuya/chongmuya/pull/59). 시작 기준은 `31fdbe8d20cfa27fee0bbe1213ddd07aeb9de915`, 브라우저 전후 비교 기준은 #58이 병합된 `9329b5835e508b5e48b5cc52898df15db2db2f0b`입니다. Before는 해당 main, After는 해당 main과 #59 변경을 합친 로컬 작업본입니다. Chromium 402×946, 1280×946에서 동일한 가짜 API 상태를 사용했습니다. 데스크톱은 원본의 모바일 프레임을 확대하지 않고 실제 앱의 중앙 배치, 넘침, 키보드 동작을 확인했습니다. 명시한 UI 변경의 전후 차이를 증거에 포함했습니다.

Figma UI 페이지의 [참석 섹션](https://www.figma.com/design/VlhXK42QbSbn4eZxI00MNS/?node-id=233-1580), [메인 흐름](https://www.figma.com/design/VlhXK42QbSbn4eZxI00MNS/?node-id=139-4596), [QR 스캔 섹션](https://www.figma.com/design/VlhXK42QbSbn4eZxI00MNS/?node-id=654-5686)과 별도 예외를 비교했습니다. 원본 링크가 각 행의 디자인 증거입니다. Figma Education 호출 한도 또는 MCP PNG 다운로드 시 클라우드 프록시의 CONNECT 403으로 픽셀을 열 수 없는 항목은 시각 **접근불가**로 둡니다. 해당 항목의 XML과 앱 기능 결과는 별개입니다. 원본 렌더 확보 항목도 데스크톱용 Figma가 없으므로 픽셀 일치를 주장하지 않습니다.

경로의 `E/G/R/P/V/S`는 행사/모임/차수/참여자/연결 검토/공개 공유 ID입니다. 앱 증거의 영문 캡션은 테스트 상태 이름입니다. `before:`가 붙은 셀은 main 캡처입니다.

## 현재 정책과 근거

- 한 사람의 차수별 최신 응답을 사용합니다. 링크와 QR은 같은 `/attendance/S`를 엽니다. 열기만으로 별도 현장 출석/정산 사실이 생성되지 않습니다. 본인 수정과 총무 정정은 구분됩니다.
- 새로고침 후 같은 브라우저에서 이름+뒤 4자리로 다시 여는 것을 브라우저에서 확인했습니다. 쿠키 없는 별도 클라이언트의 같은 응답 갱신·다른 차수 집계 보존은 [기존 격리 PostgreSQL 통합 테스트](https://github.com/chongmuya/chongmuya/blob/9329b5835e508b5e48b5cc52898df15db2db2f0b/apps/api/test/integration/attendance.test.ts#L189)에서 확인했습니다. 개인 수정 링크는 최신 정책에서 요구하지 않습니다.
- 정확 일치 한 명은 본인 응답을 엽니다. 번호가 없는 경우 유일한 이름 후보만 최초 연결합니다. 애매한 동명이인 및 동일 조합 중복은 총무에게 넘깁니다. 기존 접수된 문의 인원 스냅샷은 응답 수정 후에도 유지됩니다. [정책 원문](https://chatgpt.com/c/6afd61e2-ba60-83ee-8384-216cecc6663d?messageId=3866e3a3-16bb-5544-ac6a-a1bd70ab0119) · [식별 규칙](https://github.com/chongmuya/chongmuya/blob/9329b5835e508b5e48b5cc52898df15db2db2f0b/apps/api/src/modules/events/lib/attendance-rules.ts#L32).
- 기존 명단 가져오기 규칙은 기존 항목·응답을 보존합니다. 선택 가져오기와 직접 추가는 결과 유실 시 동일 ID·버전·요청 키로 확인합니다. 모임 정책과 parser 변경 없음.
- 실기기 카메라 QR, iOS Safari, 카카오 인앱은 사람 확인 항목입니다. 운영 계정/연락처, SMS, 결제는 사용하지 않았습니다.
